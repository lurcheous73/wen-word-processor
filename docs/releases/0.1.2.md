# Wen Word Processor 0.1.2 Alpha

First GitHub-published alpha of the offline Android word processor.

## Included

- Three offline OpenDyslexic font choices.
- Bold, italic, underline, cut, copy, paste, undo, and redo.
- Android keyboard integration for swipe typing and predictive text.
- Live document word count, folder-wide word count, and page estimate.
- A–Z, Z–A, newest-altered, and oldest-altered document sorting.
- Fully offline Vosk speech-to-text with spoken punctuation.
- Four-step voice calibration on the main editor screen.
- Bundled en-GB dictionary.
- Automatic save, atomic replacement, and interrupted-save recovery.
- Single document directory at `Documents/Wen`, with migration from the earlier `Documents/SimpleType` alpha folder.
- No INTERNET permission, cloud account, telemetry, adverts, or Android cloud backup.

## Tested

Runtime tested on an Android 16 / API 36 ARM64 tablet emulator, including hard-kill persistence, formatting persistence, clipboard, undo/redo, 3,600-word page tracking, offline model extraction, silent microphone rejection, temp-file crash recovery, and legacy folder migration.

The remaining acceptance test is speech recognition accuracy with the intended speaker on the real tablet microphone across her normal, high, low, and naturally changing registers.

This release uses a debug-signed APK for private alpha testing.
