# Wen Word Processor 0.1.4 Alpha

Brimstone branding and hardening release.

## Brimstone

- Added a dedicated About panel.
- Ported the Brimstone brand mark from the existing Control branding.
- Brimstone is shown as the company, with build/version/privacy information.
- Added a hardened-build About screenshot.

## Hardening

- Added strict document version, size, title, font and formatting-span validation.
- Added a 24 MiB on-disk document safety limit and a five-million-character editor limit.
- Corrupt or oversized documents are isolated from normal parsing and no longer risk taking down the document shelf.
- Interrupted saves promote a valid temp file only after preserving the previous target, with rollback if promotion fails.
- Invalid temp files are retained as recovery-failed evidence rather than silently deleted.
- Legacy migration only moves Wen document files.
- EditorActivity is explicitly non-exported; external launch attempts are blocked by Android.
- Android backup remains disabled and cleartext traffic remains disabled.
- Offline Vosk model integrity is checked before use; damaged or incomplete local model copies are rebuilt from bundled assets.
- Release build enables R8 code shrinking and resource shrinking while retaining Vosk/JNA native bindings.
- Debug and shrunk release variants both build successfully.

## Runtime checks

Passed on Android 16/API 36 ARM64 tablet emulator:

- Corrupt-document shelf startup with no Wen process crash.
- External direct launch of EditorActivity denied by Android.
- Invalid temp recovery preservation.
- Valid interrupted-save recovery with previous target preserved.
- Deliberately deleted Vosk acoustic model rebuilt automatically.
- Shrunk/obfuscated release APK launched and exercised the native speech path without class/link errors.
- APK permission audit still reports RECORD_AUDIO only.

The remaining acceptance test is the intended speaker's real voice on the physical tablet across normal, high, low and naturally changing registers.

This alpha APK is debug-signed for private testing.
