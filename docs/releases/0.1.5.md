# Wen Word Processor 0.1.5 Alpha

Font expansion release.

## Fonts

- Added Caveat handwriting font, bundled fully offline.
- Caveat regular and bold files are included under the SIL Open Font License 1.1.
- Added Times New Roman as a document font choice.
- Times New Roman itself is not redistributed in the APK because Microsoft/Monotype require separate application redistribution rights.
- When the Android device supplies a licensed Times New Roman system family, Wen uses it. Otherwise Wen falls back to Android's serif family.

## Existing behaviour retained

- OpenDyslexic, OpenDyslexic 3 and OpenDyslexic Mono remain available.
- Bold, italic and underline remain independent of the selected document font.
- Documents remain fully offline in the Wen document directory.
- Offline Vosk dictation and voice calibration remain unchanged.
- APK still requests RECORD_AUDIO only and has no INTERNET permission.

This remains an alpha build for private testing.
