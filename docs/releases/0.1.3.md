# Wen Word Processor 0.1.3 Alpha

Visual polish and usability pass for the tablet UI.

## Changes

- New Wen Word Processor document shelf styling.
- Visible document title in the editor.
- Navigation and Save moved to a dedicated top row.
- Formatting, clipboard, Undo/Redo, Dictate, and Calibrate voice controls organised on a separate toolbar.
- Calmer spacing and colours without adding a high-contrast mode.
- Rounded document cards and a clearer empty-library message.
- Additional content descriptions for important editing and speech controls.
- Real emulator screenshots added to the repository.

## Existing offline features

The app remains fully offline with no INTERNET permission. It includes the local en-GB dictionary, bundled Vosk speech model, OpenDyslexic font set, autosave/recovery, folder-wide word counting, and four-step voice calibration.

The remaining acceptance test is recognition accuracy with the intended speaker on the real tablet microphone across her normal, high, low, and naturally changing registers.

This is a debug-signed alpha build for testing.
